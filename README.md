# 📲 بوت تيليجرام لبيع شرائح الاتصال الإلكترونية (eSIM Store Bot - عربي بالكامل)

مستودع برمجي متكامل لإنشاء وتشغيل بوت تيليجرام احترافي باللغة العربية بالكامل لبيع شرائح **eSIM** تلقائياً على مدار الساعة (**24/7**) مع نظام أرصدة متكامل، لوحة تحكم شاملة للمالك، وإشعارات فورية للمستخدمين عند توفر مخزون جديد.

## ✨ المميزات الرئيسية

* **واجهة عربية بالكامل (100% Arabic):** جميع القوائم، الأزرار، الإشعارات، والرسائل مصممة باللغة العربية بشكل واضح وسلس.
* **إدارة الدول والباقات بمرونة كاملة:**
  * إضافة دول جديدة، تعديل أسمائها، أو حذفها.
  * إضافة باقات متعددة لكل دولة مع تحديد الاسم، الوصف (البيانات والصلاحية)، والسعر.
* **إضافة الشرائح للمخزون بطريقتين (LPA أو QR Code):**
  * يمكنك إضافة الشرائح عبر إرسال **كود LPA نصي** (أو عدة أكواد دفعة واحدة كل كود في سطر) وسيقوم البوت تلقائياً بتوليد صورة **QR Code** عالية الدقة للعميل عند الشراء!
  * أو عبر إرسال **صورة QR Code** مباشرة للبوت.
  * إمكانية معاينة، تعديل، أو حذف أي شريحة من المخزون في أي وقت.
* **إشعار جماعي تلقائي عند إضافة مخزون جديد:**
  * بمجرد إضافة شرائح جديدة لأي باقة، يرسل البوت إشعاراً عاماً لجميع المستخدمين يوضح الدولة والباقة والسعر والكمية المضافة مع زر شراء مباشر.
* **استلام فوري وخصم تلقائي للرصيد:**
  * عند شراء العميل لأي باقة، يتم التحقق من الرصيد وخصم سعر الباقة وإرسال كود الـ QR وكود الـ LPA فوراً للعميل في نفس اللحظة، مع حفظ الشريحة في قسم **«مشترياتي السابقة»**.
* **نظام شحن الرصيد (Binance ID & InstaPay EG):**
  * يدعم شحن الرصيد عبر **Binance Pay (عملات رقمية)** أو **InstaPay EG (إنستا باي مصر)**.
  * يرسل العميل المبلغ وإيصال التحويل/الرقم المرجعي ليصل فوراً إلى المالك مع أزرار **«قبول وإضافة الرصيد»** أو **«رفض الطلب»** بضغطة واحدة.
* **لوحة تحكم خاصة بمالك البوت فقط (`/admin`):**
  * إحصائيات شاملة للمتجر والمبيعات.
  * إضافة أو خصم رصيد لأي مستخدم يدوياً.
  * نظام **حظر وفك حظر المستخدمين (Ban / Unban)** بالـ ID.
  * إرسال **رسالة جماعية عامة (Broadcast)** لجميع المستخدمين (نص أو صورة).
  * تعديل إعدادات الدفع (`Binance ID`، `InstaPay EG`) ويوزر الدعم الفني مباشرة من داخل البوت.
* **تشغيل 24/7 وفتح تلقائي عند إعادة تشغيل الخادم (VPS):**
  * يحتوي المستودع على سكربت التثبيت الذكي `install.sh` الذي يطلب منك الإعدادات الأساسية أثناء التثبيت ويقوم بإنشاء وتفعيل خدمة `systemd` (`esim-bot.service`).

## 📁 هيكل ملفات المستودع

| الملف | الوظيفة |
| :--- | :--- |
| `bot.py` | الكود الرئيسي للبوت (واجهة العميل، لوحة تحكم الأدمن، توليد الـ QR، والإشعارات) |
| `database.py` | قاعدة بيانات SQLite لإدارة المستخدمين، الدول، الباقات، المخزون، وطلبات الشحن بأمان تام |
| `config.py` | قارئ ملف الإعدادات والبيئة `.env` |
| `install.sh` | سكربت التثبيت التفاعلي على خادم VPS وإعداد خدمة التشغيل التلقائي 24/7 |
| `requirements.txt` | المكاتب البرمجية المطلوبة لتشغيل البوت |
| `.env.example` | نموذج ملف متغيرات البيئة |
| `.gitignore` | لحماية ملف `.env` وقاعدة البيانات من الرفع بالخطأ على GitHub |

## 🚀 طريقة التثبيت والتشغيل على خادم VPS (Ubuntu / Debian)

1. **انسخ المستودع من GitHub إلى الخادم الخاص بك:**
   ```bash
   git clone https://github.com/faresbazed/Telegram-Bot-eSIM-Store
   cd Telegram-Bot-eSIM-Store
   ```

2. **شغّل سكربت التثبيت التفاعلي:**
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
   أثناء التشغيل، سيطلب منك السكربت إدخال القيم التالية مباشرة:
   * `BOT_TOKEN`: توكن البوت من `@BotFather`
   * `ADMIN_ID`: معرف حسابك الرقمي في تيليجرام (يمكنك معرفته عبر `@userinfobot`)
   * `SUPPORT_USERNAME`: يوزر حسابك للدعم الفني (بدون `@`)
   * `BINANCE_ID`: معرف الدفع الخاص بك في Binance
   * `INSTAPAY_ADDRESS`: عنوان الدفع أو الرقم الخاص بك في InstaPay EG
   * `CURRENCY`: عملة المتجر (مثل `USD` أو `EGP`)

3. **إدارة البوت على الخادم (يعمل تلقائياً 24/7):**
   * فحص حالة البوت: `sudo systemctl status esim-bot`
   * متابعة سجلات التشغيل: `sudo journalctl -u esim-bot -f`
   * إعادة تشغيل البوت: `sudo systemctl restart esim-bot`
   * إيقاف البوت: `sudo systemctl stop esim-bot`
